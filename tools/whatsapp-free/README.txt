CHARISNA KOST — Pendamping WhatsApp 1.0.1

Perbaikan laptop:
- Mendeteksi Chrome 64-bit, 32-bit, instalasi per pengguna, dan Microsoft Edge.
- Menampilkan penyebab startup gagal pada terminal dan halaman localhost.
- Memeriksa Node.js minimal 22.12 sebelum menjalankan dependency.

Cara memperbarui:
1. Tutup jendela pendamping versi lama pada laptop.
2. Ekstrak ZIP perbaikan ke folder baru.
3. Jalankan Jalankan-WhatsApp.cmd dan tunggu pemasangan dependency selesai.
4. Buka atau muat ulang http://127.0.0.1:8772 setelah terminal siap.
5. Tunggu QR, lalu tautkan dari WhatsApp HP jika diminta.

Sesi dan kode penghubung tetap berada di profil Windows pengguna. Jangan membagikan folder .charisna-kost-whatsapp atau kode penghubung ke orang lain.
Jika masih gagal, kirim teks error pada terminal. Jangan kirim kode penghubung, QR login, atau folder sesi.
