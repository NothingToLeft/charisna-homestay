Urutan paling mudah:

1. Jalankan START_WEB.bat untuk mencoba aplikasi.
2. Jalankan PUSH_GITHUB.bat untuk mengunggah source ke repository GitHub kosong.
3. Jalankan DEPLOY_FIREBASE_RULES.bat setelah membuat project Firebase.
4. Jalankan RELEASE_GITHUB.bat untuk memicu build otomatis EXE dan APK di GitHub.
5. BUILD_WINDOWS.bat hanya diperlukan bila ingin build EXE langsung di komputer Windows.
