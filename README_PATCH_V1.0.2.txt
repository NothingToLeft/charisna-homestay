MANAGEMENT OFFLINE SUITE - PATCH BUILD V1.0.2

1. Ekstrak seluruh isi ZIP ini ke folder utama project lokal.
2. Saat Windows bertanya, pilih Replace the files in the destination.
3. Pastikan APPLY_FIX_AND_RELEASE_V1.0.2.bat berada sejajar dengan package.json.
4. Klik dua kali APPLY_FIX_AND_RELEASE_V1.0.2.bat.
5. Buka GitHub > Actions > Build Release dan pantau tag v1.0.2.

Patch ini tidak mengubah skema database, format backup, atau struktur Firestore.
Jangan gunakan ulang tag v1.0.1 karena tag rilis bersifat tetap.
