# Operasional kebersihan

Owner masuk dengan akun Firebase `charisna.homestay@gmail.com`, lalu buka **Kelola Petugas Kebersihan**. Buat akun petugas dengan username dan PIN empat digit. Buat tugas, pilih tanggal, isi checklist satu langkah per baris, dan gunakan opsi tujuh hari bila perlu. Petugas masuk dari pilihan **Login Staff**, mengerjakan checklist, memberi catatan, dan mengunggah foto sebelum atau sesudah pekerjaan. Tugas selesai mensyaratkan semua langkah checklist dicentang.

Foto dikompresi menjadi JPEG di perangkat, lalu disimpan sementara pada koleksi Firestore `cleaningPhotos` dengan status `PENDING`. Foto maksimal 15 MB sebelum kompresi dan sekitar 250 KB setelah kompresi. Jangan unggah foto identitas penghuni atau informasi rahasia. Script privat pada `scripts/google-apps-script/Code.gs` berjalan sebagai `charisna.homestay@gmail.com` setiap 15 menit. Script memeriksa penugasan, membuat folder `CHARISNA KOST/Kebersihan/YYYY-MM-DD/Properti/Username`, memindahkan foto ke Drive, menghapus data gambar dari Firestore, lalu mengirim ringkasan ke Gmail akun yang sama. Email diberi label `CHARISNA KOST/Kebersihan`. Status `Menunggu Drive` berarti unggahan sudah di Firestore tetapi belum selesai diarsipkan.

Script hanya dipasang sebagai **time trigger** melalui `installCharisnaTriggers`; jangan terbitkan sebagai web app publik. Script membutuhkan izin Drive, Gmail, Firestore, dan pengelolaan trigger pada akun Charisna. Akun Google Charisna memiliki peran `Cloud Datastore User` pada proyek Firebase `charisna-kost-manager`; peran itu memberi akses baca/tulis ke seluruh Firestore, sehingga amankan akun dengan verifikasi dua langkah. Firebase dan GitHub tetap dikelola akun `bumimakmur002`; Drive, Gmail, dan Apps Script memakai akun Charisna. Firebase Storage tidak dipakai agar proyek tetap pada paket Spark.

Jika arsip gagal, buka **Executions** pada Apps Script dan periksa pesan error. Dokumen `PENDING` tidak dihapus otomatis; trigger berikutnya mencoba lagi. Bila Drive sudah berisi nama file yang sama, script memakai file tersebut agar pemrosesan ulang tidak membuat duplikat. Email rangkuman hanya dikirim setelah status Firestore berubah menjadi `SAVED`. Hapus tugas tidak menghapus foto yang sudah terarsip; simpan arsip sesuai kebijakan usaha.
